# Requirements and evidence

Source of truth: [preserved official specification](CHALLENGE.md), upstream commit `315891441be81ca0bff75cf3c2b0cd2f27f119cd`. Rows follow its sections and evaluation categories. Additional project safeguards are identified separately.

Statuses: **TODO** (not implemented), **IN_PROGRESS** (partial), **IMPLEMENTED** (code exists, required validation pending), **VERIFIED** (specific evidence passed), **BLOCKED** (external dependency prevents progress). VERIFIED applies only to the scope described in that row; unit-tested rules do not prove UI or production behavior.

Current evidence (2026-11-26): **42 unit tests passed**, **53 optimized-build browser tests passed** with one intentional desktop multitouch duplicate skipped, and **24 public browser checks passed**. Six visual baselines passed comparison. Typecheck, lint and production build passed. Performance, memory retaining paths and required accessibility checks are documented in PERFORMANCE.md and ACCESSIBILITY.md. G14 (continuous spawning) and E07 (separate clean checkout) remain open. Repository handoff is tracked separately from runtime publication.

Evidence abbreviations: **Core** = `src/game/simulation.test.ts`; **Data** = `src/api/data.test.ts`; **Foundation** = `tests/e2e/foundation.spec.ts`; **Lifecycle** = `tests/e2e/lifecycle.spec.ts`; **Combat** = `tests/e2e/combat.spec.ts`; **Resources** = `tests/e2e/resources.spec.ts`; **Network** = `tests/e2e/network.spec.ts`; **Accessibility** = `tests/e2e/accessibility.spec.ts`; **Visual** = `tests/visual/screens.spec.ts`.
